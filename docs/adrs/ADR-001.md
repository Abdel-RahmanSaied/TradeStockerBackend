# ADR-001: Modular Go core with three entrypoints

Status: Accepted scope baseline; physical paths require S00 reconciliation

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Use platform-core, market-ingestion and Python research-worker; isolate online/batch worker groups without a service for each role.

## Tradeoffs

Simpler operations and coherent domain transactions; independent scaling remains possible at justified boundaries.

## Alternatives not selected

Many microservices from day one; a monolithic unbounded agent process.

## Implementation and validation

Start with `S01-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
