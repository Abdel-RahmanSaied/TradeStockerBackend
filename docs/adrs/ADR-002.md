# ADR-002: Go authority and Python research

Status: Accepted scope baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Go owns ledger/policy/advice lifecycle. Python owns AI/quant research and returns typed assessments; no direct core writes.

## Tradeoffs

Strong authority boundary and access controls; explicit contracts/serialization are required.

## Alternatives not selected

Python and Go both writing portfolio state; autonomous chief-agent approval.

## Implementation and validation

Start with `S02-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
