# ADR-004: JetStream plus outbox/inbox

Status: Accepted design baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Use bounded durable event transport, transactionally persisted outbox and consumer business-idempotency keys.

## Tradeoffs

Requires crash-window tests and explicit ordering; does not promise exactly-once external delivery.

## Alternatives not selected

Uncoordinated DB+publish writes; duplicate event buses without a measured need.

## Implementation and validation

Start with `S02-T04` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
