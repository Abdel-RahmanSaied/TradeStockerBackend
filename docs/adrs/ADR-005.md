# ADR-005: Human-only execution as an architectural prohibition

Status: User-approved invariant

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

No broker order APIs/tools/credentials. Record past human fills separately from advice acknowledgment.

## Tradeoffs

Cannot guarantee timely entry/exit; latency and missed fills must be modeled.

## Alternatives not selected

Automated execution behind an approval button; inferred fills.

## Implementation and validation

Start with `S01-T06` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
