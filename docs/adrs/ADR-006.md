# ADR-006: One deterministic policy implementation for live and replay

Status: Accepted design baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Use a pure Go policykernel and a batch runner for Python replay. Financial effects remain transactional Go operations.

## Tradeoffs

Cross-language interface adds work but prevents silent policy drift.

## Alternatives not selected

Independent Python/Go rule copies with informal parity.

## Implementation and validation

Start with `S05-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
