# ADR-007: Point-in-time evidence and immutable corrections

Status: Accepted scope baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Track publication/availability/ingestion; archive versions and preserve historical universes.

## Tradeoffs

Higher metadata/storage requirements; historical missing data remains a limitation rather than a fabricated repair.

## Alternatives not selected

Latest-only datasets in backtests; retroactive restatement replacement.

## Implementation and validation

Start with `S06-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
