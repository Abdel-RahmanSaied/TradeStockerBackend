# ADR-008: Conditional hierarchical advisory roles

Status: Accepted scope baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Implement eighteen logical research/control roles plus five trading specialists with capability routing and bounded debate.

## Tradeoffs

Needs explicit required inputs and evaluation; role agreement is not independent probability evidence.

## Alternatives not selected

Twenty-three services or unconditional model calls per price update.

## Implementation and validation

Start with `S08-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
