# ADR-009: Goals cannot expand risk authority

Status: User-approved invariant

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Target, forecast and risk budget are distinct. Goal engine may abstain or propose horizon/target review, never auto-raise limits.

## Tradeoffs

May fail to attain targets; protects policy integrity rather than promising returns.

## Alternatives not selected

Deadline-driven position scaling or forced daily trade quotas.

## Implementation and validation

Start with `S12-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
