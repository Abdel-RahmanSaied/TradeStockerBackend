# ADR-010: Independent four-lane activation

Status: Accepted scope baseline

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Each market/horizon advances through data/replay/shadow/paper/release gates separately with owner approval.

## Tradeoffs

More evaluation bookkeeping; failure in one lane need not disable qualified independent lanes.

## Alternatives not selected

One pooled performance score or global auto-enable after deployment.

## Implementation and validation

Start with `S15-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
