# ADR-011: Independent trading core with optional OpenClaw interface

Status: User-approved decision; reconcile any existing ADR-011 at S00

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

OpenClaw is a last-phase, read-only optional interface. Core analysis, policy and official Telegram cannot depend on it.

## Tradeoffs

An additional adapter is needed later; the core remains replaceable and independently operable.

## Alternatives not selected

Hosting the whole trading platform inside OpenClaw.

## Implementation and validation

Start with `S16-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
