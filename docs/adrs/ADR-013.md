# ADR-013: AWS deployment baseline with explicit cost/HA approval

Status: Proposed implementation detail; resolve D-06

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Prefer ECS app workers, RDS and S3; choose managed or dedicated durable NATS and approved failure domains.

## Tradeoffs

Operational familiarity, but ongoing cost and HA need approval; no claim a single VM is HA.

## Alternatives not selected

Kubernetes before operational need; ephemeral stateful message storage.

## Implementation and validation

Start with `S14-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
