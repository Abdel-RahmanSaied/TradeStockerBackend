# ADR-015: Safe implementation discovery and no silent overwrite

Status: Accepted planning convention

Date: 2026-10-23

Implementation evidence: **None at bootstrap.**

## Context

TradeStocker must support EGX/US swing and intraday advice, Telegram and a human-only execution boundary. This decision reflects the current plan; repository reconciliation and validation are still required.

## Decision

Inspect existing repository and instructions before scaffolding; installation refuses changed-file conflicts and preserves root instructions.

## Tradeoffs

May require manual reconciliation of existing docs; no guessed migration or destructive reset.

## Alternatives not selected

Assuming a blank repo or overwriting an established AGENTS/source-of-truth.

## Implementation and validation

Start with `S00-T01` in the task catalog. Link tests and review evidence before treating this as implemented. Revisit only through an approved new/superseding ADR; never silently rewrite an existing accepted safety boundary.
