## S02-T01 — Implement OpenAPI and event-schema ownership

**Owner role:** Backend Engineers · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S01-T01`, `S01-T03`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-01`, `REQ-06`, `REQ-15`

### النطاق

Turn CONTRACTS.md into executable OpenAPI and versioned JSON Schemas. Generate or validate Go and Python payload types from the same contracts.

### المخرجات المقترحة

- `contracts/openapi/`
- `contracts/events/v1/`
- `contracts/fixtures/`

### معايير القبول

- Decimal values cross service boundaries as strings; timestamps are UTC RFC3339.
- Envelope contains event/causation/correlation IDs, schema version and producer build.
- Unknown enum values and breaking schema changes fail compatibility tests.
- Execution-report endpoints record past human fills; no order-submission endpoint exists.

### التحقق والاختبارات

- Cross-language round-trip golden fixtures and invalid-payload tests.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.


## S02-T02 — Create database migrations, owners and index conventions

**Owner role:** Go + Data Engineers · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S02-T01`, `S01-T04`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-05`, `REQ-08`, `REQ-12`

### النطاق

Create core, market, research and audit schemas with least-privilege roles, migration locking, numeric precision choices and ownership boundaries.

### المخرجات المقترحة

- `db/migrations/`
- `db/queries/`
- `sqlc.yaml`
- `docs/evidence/schema-baseline.md`

### معايير القبول

- Fresh database migration and prior-version upgrade both succeed.
- Foreign keys, uniqueness, account ownership and positive quantity checks are enforced where applicable.
- Money uses exact numeric representation and documented rounding.
- Migration rollout is expand/contract; irreversible data changes are not described as app rollback.

### التحقق والاختبارات

- Test migration from empty and previous fixture DB; test constraints with invalid records.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.

## S02-T04 — Implement outbox, inbox and replay-safe consumers

**Owner role:** Go + Python Engineers · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S02-T01`, `S02-T02`, `S01-T05`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-05`, `REQ-12`

### النطاق

Add transactional outbox for domain writes, durable consumers, inbox identities and controlled retries. Treat transport and business idempotency as different boundaries.

### المخرجات المقترحة

- `internal/events/`
- `research/src/events/`
- `db/migrations/<outbox-inbox>.sql`

### معايير القبول

- Domain row and outbox row commit atomically.
- Crash after processing and before ACK cannot duplicate a ledger effect or recommendation.
- Poison messages are quarantined after a bounded retry policy with replay tooling.
- Consumer ordering/aggregate versions and inbox retention are explicitly documented.

### التحقق والاختبارات

- Crash-window tests before/after DB commit, publish acknowledgment and consumer acknowledgment.
- Replay the same batch repeatedly and verify stable business-state counts.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.


## S02-T05 — Implement durable schedules, leases and workload isolation

**Owner role:** Go + Platform Engineers · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S02-T03`, `S02-T04`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-02`, `REQ-05`, `REQ-12`

### النطاق

Add scheduled job records keyed by job, market session and due time; use leased claims with fencing for duplicate runners. Separate live research from batch/replay consumers.

### المخرجات المقترحة

- `internal/scheduling/`
- `deploy/nats/`
- `docs/evidence/scheduler-tests.md`

### معايير القبول

- Two scheduler instances cannot produce two logical jobs for one slot.
- Expired owner cannot commit after lease takeover.
- A missed run has an explicit catch-up/skip policy.
- Replay subjects and storage cannot emit production Telegram effects.

### التحقق والاختبارات

- Concurrent scheduler, clock-skew, lease-expiry and stale-owner tests.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.


## S02-T06 — Persist raw evidence and dataset manifests

**Owner role:** Data Engineer · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S02-T02`, `S02-T04`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-03`, `REQ-04`, `REQ-05`, `REQ-13`

### النطاق

Persist immutable source objects, metadata, hashes, entitlements and versioned Parquet manifests. Large documents travel by references, not by event payload.

### المخرجات المقترحة

- `internal/evidence/`
- `research/src/datasets/`
- `contracts/datasets/`

### معايير القبول

- Object checksum and source identity are stored with publication and ingestion times.
- Corrections create linked versions rather than silently replacing historical evidence.
- Retention/encryption/access reflect the provider contract.
- A manifest deterministically identifies input files and adjustment versions.

### التحقق والاختبارات

- Corrupt-object, missing-object and corrected-document fixtures.
