## S06-T01 — Build point-in-time dataset loader

**Owner role:** Python Quant Engineer · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S03-T05`, `S02-T06`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-03`, `REQ-04`, `REQ-09`

### النطاق

Load only the information available at each historical decision time, including filings, revisions, instrument universe and macro vintages.

### المخرجات المقترحة

- `research/src/backtest/datasets/`
- `tests/leakage/`

### معايير القبول

- Economic period-end is never used as publication time.
- Restatements and future-adjusted data cannot leak into earlier decisions.
- Training, validation and holdout datasets have immutable manifests.
- Unavailable history is explicitly excluded or marked, never reconstructed with future knowledge.

### التحقق والاختبارات

- Inject future facts and verify rejection; test delisted/ticker-reused instruments.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.


## S06-T02 — Implement event-driven fill and human-latency simulator

**Owner role:** Python Quant Engineer · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S06-T01`, `S05-T01`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-02`, `REQ-06`, `REQ-09`

### النطاق

Simulate decision time, alert delay, human response and feasible fills separately. Reuse policy-eval and market/account rules.

### المخرجات المقترحة

- `research/src/backtest/simulator/`
- `fixtures/execution/`

### معايير القبول

- Include bid/ask spread, slippage, fees, partial/non-fills, halts and limit states.
- Bar-only tests use conservative ambiguity handling for stop/target in the same bar.
- Intraday cutoff cannot guarantee an exit during a halt; carry residual exposure explicitly.
- Avoid assuming fills at the signal bar close or prices before the user could act.

### التحقق والاختبارات

- Golden scenarios for gaps, halt, delayed human, invalid order size and same-bar ambiguity.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.

## S06-T04 — Preregister holdouts, thresholds and trial accounting

**Owner role:** Quant + Risk Reviewer · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S06-T03`, `S00-T05`

**Decisions to review:** `D-07`, `D-09`

**Requirements:** `REQ-09`, `REQ-14`

### النطاق

Define walk-forward splits, purging/embargo where horizons overlap, experiment tracking and release thresholds before strategy selection.

### المخرجات المقترحة

- `research/experiments/`
- `docs/evidence/evaluation-preregistration.md`

### معايير القبول

- Every tested strategy/prompt/model configuration is counted, not only winners.
- Sample-size and uncertainty criteria are approved per lane before unblinding holdouts.
- No arbitrary win-rate number is presented as a release guarantee.
- Threshold changes after results require a new experiment and new untouched evaluation data.

### التحقق والاختبارات

- Validate manifest split overlap, embargo rules and rejected retrospective threshold edits.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.


## S06-T05 — Build replay determinism and live-feature parity tests

**Owner role:** Go + Python Engineers · **Priority:** P0 · **Relative size:** M

**Dependencies:** `S06-T02`, `S03-T04`, `S05-T01`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-05`, `REQ-09`, `REQ-12`

### النطاق

Run the same recorded events through live and replay feature/policy paths; record intentional numeric tolerances only for statistical outputs.

### المخرجات المقترحة

- `tests/parity/`
- `research/src/replay/`

### معايير القبول

- Policy outcomes and monetary values match exactly.
- Indicator warmup, missing data and session reset rules match across execution modes.
- No replay pipeline can send a production message.
- Clock source and randomized seeds are controlled and recorded.

### التحقق والاختبارات

- Byte/digest checks for deterministic outputs and approved numeric tolerance tests.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.
