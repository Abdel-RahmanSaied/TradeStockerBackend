# S16 — OpenClaw: طبقة اختيارية للقراءة فقط

**Technical scope:** Optional OpenClaw read-only interface

> ملف مولّد؛ مصدر التعريف `../state/task_catalog.json`. الحالة الفعلية في `../state/project_state.json`، وليست في checkboxes هنا.

**اختياري:** نعم؛ يتطلب اعتمادًا منفصلًا.

## الهدف

Add an optional explanation interface only after core operation is established and explicitly authorized.

## بوابة الخروج

Removing or compromising the optional assistant cannot submit orders, change risk, mutate portfolio state or stop official notifications.

**Dependencies:** `S15-T06`

**Decisions to review:** `D-11`

**Requirements:** `REQ-14`

## S16-T02 — Expose narrowly scoped read-only assistant API

**Owner role:** Go Engineer · **Priority:** P2 · **Relative size:** M

**Dependencies:** `S16-T01`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-06`, `REQ-12`, `REQ-14`

### النطاق

Provide approved report/explanation endpoints with dedicated read-only identity and field-level privacy filtering.

### المخرجات المقترحة

- `internal/http/assistant_readonly/`

### معايير القبول

- No DB/NATS access or write credentials.
- No risk, strategy, portfolio or recommendation mutation API.
- Every response carries revision/time and permission-filtered evidence references.

### التحقق والاختبارات

- Read-only scope, cross-account and privilege-escalation tests.

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.

## S16-T04 — Verify isolation and zero core dependency

**Owner role:** Security + QA · **Priority:** P2 · **Relative size:** M

**Dependencies:** `S16-T03`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-06`, `REQ-12`, `REQ-14`

### النطاق

Disconnect and compromise the assistant in a controlled test; verify core analysis, official Telegram and monitoring continue.

### المخرجات المقترحة

- `docs/evidence/openclaw-isolation.md`

### معايير القبول

- Core startup and release do not require assistant availability.
- Read-only credentials cannot mutate state or publish events.
- Assistant outage creates no trading-platform outage.

### التحقق والاختبارات

## S16-T05 — Add revocation, retention and bounded cost controls

**Owner role:** Platform Engineer · **Priority:** P2 · **Relative size:** M

**Dependencies:** `S16-T03`

**Decisions to review:** No additional decision ID.

**Requirements:** `REQ-12`, `REQ-14`

### النطاق

Provide credential revocation, query limits and audited access, with minimum retention and a dedicated cost ceiling.

### المخرجات المقترحة

- `docs/runbooks/openclaw.md`

### معايير القبول

- Single revocation disables the assistant identity without affecting core services.
- Sensitive prompts/responses follow approved retention.
- Assistant traffic cannot starve live workloads.

### التحقق والاختبارات

**Evidence:** أضف دليلًا فعليًا داخل `docs/evidence/` واربطه بالحالة. لا تعني هذه القائمة أن الملفات أو الاختبارات موجودة الآن.
